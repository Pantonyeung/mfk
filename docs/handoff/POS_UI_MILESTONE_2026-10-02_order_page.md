# MFK POS UI 里程碑｜訂單頁延伸｜2026-10-02

## 已鎖定畫面
- 沿用目前點單頁視覺系統：淺藍／白、圓角卡片、窄側邊欄、同一品牌層級與密度。
- 購物車頂部結構鎖定：
  - 左：流水號
  - 中：整理開關
  - 右：組合開關
  - 第二行：外賣／堂食切換 + 總數量
- 「整理」只係單一開關：關閉＝原單；開啟＝整理後視圖。
- 底部保留：垃圾桶、取單、結帳。

## 今輪延伸
- 由目前點單頁延伸至「訂單頁／訂單詳情」。
- 訂單詳情以同一設計語言呈現，包含：
  - 訂單身份／流水號
  - 用餐方式
  - 下單時間／店員／取餐時間／備註
  - 商品明細與數量／價格
  - 小計、包裝費、折扣、總計
  - 關閉／返回入口
- 訂單頁係現有交易 truth 的投影，不另建第二 Order / Pricing authority。

## 下一手

- 需保持：來源、狀態、時間、金額、外賣／堂食、例外 badge 可一眼識別。
