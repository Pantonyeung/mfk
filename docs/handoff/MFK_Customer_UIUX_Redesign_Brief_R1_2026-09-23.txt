TARGET UX
- Mobile-first food ordering experience
- Clear Golden Path: Home -> Menu -> Product Config -> Cart -> Checkout -> Submit certainty -> Store acceptance -> Preparing/Delay -> Ready -> Pickup verification -> Completed -> History/Reorder
- One primary task per screen
- Normal customer UI must not expose raw UUID / engineering identifiers
- Error states repair locally; do not reset the whole journey
- READY must not imply handed-over/completed
- UNKNOWN must never become FAILED or trigger blind resubmit
- Sold-out / unavailable options are clear and non-selectable
- Quote freshness/material change must be visible before submit
- Accessibility: usable touch targets, focus states, status messages, not color-only

VISUAL DIRECTION
