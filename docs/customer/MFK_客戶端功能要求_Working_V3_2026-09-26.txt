MFK 客戶端功能要求｜Working V3
日期：2026-09-26
狀態：需求收集中
里程碑：首頁核心框架 + 非營業瀏覽／記憶罐權利已鎖

0｜已鎖產品形態
- 客戶端 = PWA / Web
- Mobile First
- 底部固定五導航：首頁 / 點單 / 記憶罐 / 訂單 / 會員
- 記憶罐 = 購物車，固定中央

1｜首頁定位
- 首頁 = 品牌門面 + 即時營運資訊 + 商品／活動導流
- 大圖優先
- 頂部固定 Logo + 營業狀態
- 底部固定五導航
- 中間內容垂直滾動

2｜首頁內容
A. 大圖主視覺：廣告／主推產品／活動／品牌內容
B. 公告／營運資訊：營業狀態／公告／售罄／今日推薦
C. Top 6 推薦：
- Admin 設定推薦 Pool
- 每個新 Session 揀 6 個
- 同一 Session 保持穩定
- 售罄／不可售自動排除
- 不重覆商品
D. 三快捷入口：
1. 記憶券
2. 常購清單
3. 磨飯日曆

3｜磨飯日曆
- 休息日
- 特別營業安排
- 本週限定
- 節日活動
- 未來活動／會員相關日程（有正式功能先顯示）
首頁公告 = 現在最重要
磨飯日曆 = 未來有咩值得再返來

4｜非營業狀態下客戶權利
Owner 原則：「非營業中」不等於停止客戶所有操作。

非營業時仍允許：
- 瀏覽首頁
- 瀏覽菜單
- 查看商品
- 配置商品
- 加入記憶罐
- 編輯記憶罐
- 查看會員／優惠／常購／磨飯日曆等非交易內容

正式提交邊界：
- 建立正式訂單前重新驗證店舖是否可接單
- 如非營業：
  - 不建立正式 Order
  - 不分配正式 Order Number
  - 不清空記憶罐
  - 不刪除客戶已選內容
  - 顯示目前非營業時間，暫未能提交訂單
  - 有資料時顯示下一次營業時間
- 客戶可保留內容，之後再回來提交

未鎖：
- 是否允許非營業時進入 Checkout 最後一步
- 是否支援預約／未來時段落單

5｜首頁手勢
- 頂部 Pull-to-refresh
- 正常滾到底不顯示彩蛋
- 到底後再額外向上拖過門檻才觸發
- 不依賴壓力感應；以 drag distance / velocity / release threshold 判定

6｜關鍵產品原則
- 營業狀態是提交資格，不是瀏覽權
- 非營業中不得清空記憶罐
- 首頁、點單、記憶罐仍可正常使用
- 正式提交前 fresh-check 接單資格
- 未來預約單需另立正式 contract
