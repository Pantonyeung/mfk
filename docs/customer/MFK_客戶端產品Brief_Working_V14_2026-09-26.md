# MFK 客戶端產品 Brief｜Working V14
日期：2026-09-26
狀態：訂單／最愛／常用訂單第一版

## 訂單頁第一層

我建議唔整太多 Tab：

**進行中｜已完成｜全部**

每張卡一定有：
- 狀態
- 時間
- 商品摘要
- 金額
- 取餐碼
- 流水號
- 查看詳情

進行中會自動更新；
完成單保持歷史紀錄。

## 「再來一單」我支持，但唔係直接重開舊單

正確：

```text
舊 Order
→ 複製內容
→ 建新 Cart
→ 重新驗價錢／售罄／選項
→ 冇問題就直去 Final Review
→ 新 Order
```

這樣客人夠快，
又不會把三個月前的價錢直接拿來成交。

## Product Heart

Product Card 右上角：

♡ → ♥  

單 Tap 收藏。

動畫可以做你要的：
大心彈一下
→ 2–3 粒細心散開
→ 收回成紅心

我不建議 Double Tap，
因為商品卡本身 Tap 已經是進 Detail，
會產生手勢衝突。

## 一整套常食內容

我建議叫：
**常用訂單**

例：
「鹽酥雞飯團＋薯角＋凍奶茶」

客人收藏整張 Order 後，
它不是把舊 Order 變成可編輯；
而是保存一個「下次再來」模板。

使用時重新建立 Cart。

## 將你之前的「常購清單」真正接起來

首頁已有：
「常購清單」

我建議點入後：

```text
常購清單

[喜愛商品] [常用訂單]
```

喜愛商品：
所有 ♥ Product

常用訂單：
客人主動保存的整套組合

這樣首頁、商品卡、訂單頁全部連成同一套系統，
唔需要再開第六個導航。

## 快速程度

常用訂單按「再來一單」：

如果全部內容仍有效：
直接去記憶罐 Final Review。

如果只係一杯飲品停售：
只叫客人換飲品。

唔會要佢整單由頭揀。
