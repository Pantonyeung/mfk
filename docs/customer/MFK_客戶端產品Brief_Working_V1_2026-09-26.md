# MFK 客戶端產品 Brief｜Working V1

日期：2026-09-26
狀態：需求收集中

## 已鎖產品方向
客戶端採用 PWA / Web，手機優先。主要用途是讓客戶用手機瀏覽、點餐及落單。

## 已鎖第一層資訊架構
底部固定五個主導航，由左至右：
1. 首頁
2. 點單
3. 記憶管
4. 訂單
5. 會員

第 3 項固定置中，「記憶管」目前定義為購物車功能。

## 產品角色初稿
- 首頁：品牌與高價值入口，不等於完整菜單。
- 點單：菜單與選購主工作區。
- 記憶管：本次購買意圖／購物車。
- 訂單：訂單追蹤與歷史。
- 會員：會員身份及會員相關功能。

## 目前要防止的問題
1. 首頁與點單內容重複，令導航失去意義。
2. 把「記憶管」只當裝飾入口，而沒有清楚 Cart／Checkout 狀態。
3. 訂單頁把進行中、完成、歷史全部混成一條清單。
4. 會員頁第一版堆入過多低頻功能。

## 下一步
逐一拆「首頁」的內容、卡片、入口、優先次序及狀態。
