# MFK 客戶端產品 Brief｜Working V2

日期：2026-09-26
狀態：需求收集中
里程碑：首頁核心框架已確認

## 首頁角色
首頁係品牌門面，不是菜單複製版。第一屏同時做到：
- 有品牌吸引力
- 客人知道店舖現在可唔可以落單
- 有清楚入口引導繼續點餐

## 固定框架
頂部固定：Logo + 營業狀態
中間可上下滾動：大圖／公告／Top 6／三入口／其他內容
底部固定：首頁／點單／記憶罐／訂單／會員
記憶罐固定正中間，功能 = Cart。

## 大圖策略
- 全寬 Hero
- 活動、主打產品、品牌故事
- 固定比例
- 首圖優先載入
- 其餘延遲載入
- 手機尺寸圖片，避免過重

## 營運資訊
需要營業狀態、公告、售罄、推薦。
優先順序：
1. 阻止落單的狀態
2. 重要公告
3. 售罄／供應異常
4. 推薦／品牌內容

## Top 6
Admin 管理推薦 Pool，客戶端選出 6 個。
建議：
- 新 Session 換一組
- 同一 Session 不變
- 售罄自動剔除
- 不重覆
- 日後可支援固定位置、權重、輪換

## 三個快捷入口
1. 記憶券
2. 常購清單
3. 待決

第三入口建議用「磨飯日曆」：
- 休息日
- 特別營業
- 本週限定
- 節日活動
- 會員日／限定內容

## 手勢
頂部：拉到最頂後再向下拖 → Refresh
底部：正常到底不顯示；再額外向上拖過門檻 → 彩蛋

「用力」不應定義為手指壓力。PWA／iPhone Web 應用拖動距離＋速度＋放手門檻判斷。

## 風險
- 首頁過度資訊化
- Top 6 太隨機造成跳位
- 固定 Header + 固定 Bottom 令可視高度不足
- 彩蛋手勢誤觸
