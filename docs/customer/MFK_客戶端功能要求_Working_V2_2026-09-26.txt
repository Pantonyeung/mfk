MFK 客戶端功能要求｜Working V2
日期：2026-09-26
狀態：需求收集中
里程碑：首頁核心框架已確認

0｜已鎖產品形態
- 客戶端 = PWA / Web
- Mobile First
- 主要用途 = 手機瀏覽、點餐、落單
- 底部固定五導航：
  1. 首頁
  2. 點單
  3. 記憶罐
  4. 訂單
  5. 會員
- 第 3 項「記憶罐」固定正中間
- 記憶罐 = 購物車功能

1｜首頁定位
首頁 = 品牌門面 + 即時營運資訊 + 商品／活動導流。
Owner 明確要求：
- 圖片必須大
- 視覺要有吸引力
- 主要圖片可用於廣告、產品推介、活動、品牌內容
- 中間內容區可上下滾動

2｜固定區域
頂部固定：
- 公司 Logo
- 店舖營業狀態

底部固定：
- 首頁 / 點單 / 記憶罐 / 訂單 / 會員

中間：
- 只有中間內容區上下滾動

3｜首頁內容順序
A. 大圖主視覺區
- 全寬大圖
- 廣告／主推產品／品牌內容／活動
- 支援多張內容
- 是否自動輪播待定

B. 公告／即時狀態
- 店舖公告
- 特別營業安排
- 售罄提示
- 今日推薦
- 按重要度排序，避免 Banner 牆

C. Top 6 推薦
- 固定顯示 6 個推薦窗口
- Admin 可設定推薦 Pool
- 每次新 Session 從 Pool 抽出 6 個
- 同一 Session 內保持穩定
- 售罄／不可售項目自動排除
- 同一批次不得重覆同一商品
- 日後可支援固定／輪換／權重模式

D. 三個功能入口
1. 記憶券
2. 常購清單
3. 第三入口待最後決定

第三入口建議：「磨飯日曆」
- 本週限定
- 特別營業日
- 休息日
- 節日安排
- 活動日
- 會員日／限定內容（如日後有）

4｜首頁手勢
向下拉：
- 內容已在最頂部
- 再向下拉到指定距離
- 觸發刷新
- 顯示 loading / 更新完成

底部彩蛋：
- 正常滾到底不立即顯示
- 到達最底後，再向上拉超過額外門檻先觸發
- 不依賴按壓力度
- 用額外拖動距離／滑動速度／release threshold 判斷
- 不能影響正常滾動及底部導航

5｜重要規則
- 大圖不能令首頁首屏載入過慢
- 首張主圖優先載入，其餘 lazy load
- 圖片固定比例，避免 layout shift
- 使用手機適配圖片尺寸
- 底部導航處理 iPhone Safe Area
- Top 6 不可每次 render 重新洗牌
- 售罄資訊與 Top 6 讀同一可售狀態
- 公告／售罄／推薦要有優先級

6｜待決
- Hero 單張 / 多張
- 是否自動輪播
- 公告視覺形式
- 售罄顯示方式
- Top 6：2×3 / 單欄大卡
- Pool 最小數量、權重、固定位置
- 第三入口是否正式鎖「磨飯日曆」
- 彩蛋內容
- Refresh 與 PWA 原生手勢處理
