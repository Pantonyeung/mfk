## 本輪新增決定

### 磨飯日曆
第三個首頁快捷入口採用「磨飯日曆」方向，聚合休息日、特別營業、本週限定、節日活動及日後正式存在的會員活動。

### 非營業中仍可瀏覽與建立記憶罐
店舖關門，只代表現在不能正式提交訂單；不代表封鎖客戶瀏覽與選購。

客戶仍可：
- 睇首頁
- 睇菜單
- 睇商品
- 做商品配置
- 加入／編輯記憶罐
- 睇會員、優惠、常購、磨飯日曆

正式訂單提交前重新驗證店舖接單狀態。

如果當刻非營業：
- 不建立正式 Order
- 不分配正式訂單號
- 不清空記憶罐
- 保留已選內容
- 顯示目前未能提交
- 有資料時顯示下一次營業時間

## 產品判斷
Browse / Build Cart 與 Commit Order 是不同邊界。
關門應限制正式提交，不應限制客戶建立購買意圖。
